# CCNA 학습 기록

CCNA 합격을 목표로 하면서, 네트워크가 동작하는 원리를 이해하고 설정과 장애 분석에 적용하는 것을 목표로 한 1:1 수업의 기록입니다.

## 학습자 프로필

| 항목 | 내용 |
|---|---|
| 목표 시험 | 200-301 CCNA **v1.1** (2027-02-02까지 응시 가능) |
| 목표 시험일 | 결정 대기: 11월 유지 또는 2027년 1월 셋째 주(권장). [study-plan.md](study-plan.md) 참고 |
| 공부 가능 시간 | 평일 주 3회 × 1시간, 토·일 각 2시간 (주 7시간) |
| 집중 가능 시간 | 한 번에 20분 → 수업을 20분 블록 단위로 나눔 |
| 실습 환경 | Windows PC, Cisco Packet Tracer(설치 예정), GNS3(설치 예정) |
| 실무 경험 | Genians NAC 구축, NAC 장비 설정 |
| 이론 학습 경험 | 없음 |

## 수업 규칙

- **20분 블록:** 설명 약 8분 → 원리를 직접 설명하거나 결과를 예측하기 약 5분 → 문제나 짧은 실습 약 7분. 블록 사이에 5분 쉽니다.
  - 평일 1시간: 블록 2개와 복습 10분
  - 토·일 2시간: 블록 4개 (실습 위주)
- **내용 구분:** 수업 내용에 `[시험]`(공식 시험 범위)과 `[실무+]`(시험 범위 밖의 실무 지식)를 표시합니다.
- **오답 분류:** 개념 부족 / 계산 실수 / 문제 해석 오류 / 명령어·용어 기억 부족
