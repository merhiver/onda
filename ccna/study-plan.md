## 2. 주간 루틴 (주 7시간)

수업은 20분 블록으로 나눠요. 블록 사이에 5분 쉬어요.

| 요일 | 시간 | 구성 |
|---|---|---|
| 평일 3회 | 1시간 | 복습 퀴즈 10분 → 이론 블록 → 확인 문제 블록 → 정리 5분 |
| 토 | 2시간 | 실습 블록 3개 + 서브넷 계산 연습 블록 1개 |
| 일 | 2시간 | 실습 블록 1~2개 + 주간 퀴즈 블록 1개 + 오답 정리 블록 1개 |

- **주간 시간 배분:** 이론 약 2시간, 실습 약 2.5시간, 복습과 문제 풀이 약 2.5시간
- **주간 퀴즈:** 직접 만든 문제로 풀어요. 객관식, 서브넷 계산, 명령어 출력 해석, 장애 원인 분석을 섞어요.
- **서브넷 계산 연습:** 2주차부터 매일 5분씩, 5문제를 풀어요.
- **누적 점검:** 4주마다 이전 주제의 취약점을 다시 문제로 확인해요.
