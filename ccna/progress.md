### 영역별 진단 요약

| 영역 (비중) | 결과 | 판단 |
|---|---|---|
| Network Fundamentals (20%) | 1번 ❌, 2번 ❌ | **기초부터 학습 (최우선).** 서브넷 계산을 모르고, MAC 주소에 대한 오해가 굳어 있음 |
| Network Access (20%) | 3번 ✅ (추론), 4번 ❌/△ | 실무 감각은 있으나 원리(트렁크, STP 선출 규칙)가 부족함 |
| IP Connectivity (25%) | 5번 ✅✅, 6번 ❌ | 라우팅 테이블 판단 직관은 좋음. OSPF는 모름 |
| IP Services (10%) | 7번 ✅ (추론) | 실무 감각은 있으나 원리(DORA, Relay)가 부족함 |
| Security Fundamentals (15%) | 8번 2/3, 9번 ❌❌ | ACL 순서 처리는 이해함. 암묵적 거부와 802.1X 원리가 부족함 |
| Automation (10%) | 10번 1/2 | JSON 기초가 부족함 |

- **강점:** 실무 경험으로 결과를 예측하는 직관이 있음 (3, 5, 7, 8번). 모르는 것을 "모름"이라고 정확히 답함.
- **약점:** 원리, 용어, 프로토콜 규칙. 확신도가 '확실'인 정답이 하나도 없음.
- **진행 방식:** 기초(캡슐화, 서브넷)는 천천히 확인하며 진행하고, 실무 감각이 있는 영역(VLAN, DHCP)은 빠르게 원리만 보강함. 1~2회차 수업 뒤 속도를 다시 조정함.

## 취약점

| 우선순위 | 내용 | 근거 |
|---|---|---|
| 높음 | MAC 주소는 구간(hop)마다 바뀐다는 점. 라우터가 L2 헤더를 새로 만든다는 점 | 진단 1번. 확신도가 '확실'인데 틀림 → 고정된 오해 |
| 높음 | 서브넷 계산 (네트워크 주소, 브로드캐스트 주소, 호스트 범위, 호스트 수) | 진단 2번. 배운 적 없음. IP 주소 설계, 라우팅, ACL의 기초라 우선 학습 필요 |
| 중간 | 트렁크 동작 원리 (802.1Q 태그, allowed VLAN, native VLAN) | 진단 3번. 실무 감각으로 맞혔지만 원리를 설명하지 못함 |
| 높음 | STP (루트 브리지 선출, 루프가 생기는 원리, 포트 역할) | 진단 4번. 선출 규칙을 모름 |
| 높음 | OSPF (네이버 조건, 설정, 와일드카드 마스크) | 진단 6번. 모름 |
| 중간 | DHCP 동작(DORA)과 Relay 원리 | 진단 7번. 실무 감각으로 맞혔지만 원리를 설명하지 못함 |
| 높음 | ACL 암묵적 거부(implicit deny) | 진단 8번 ③. '규칙이 없으면 통과'라고 오해함 |
| 높음 | 802.1X 구성 요소와 동작 (EAPoL, RADIUS, 인증 전 포트 상태) | 진단 9번. 실무 영역과 가깝지만 용어와 원리를 모름 |
| 중간 | JSON 자료형, REST API (CRUD와 HTTP 메서드) | 진단 10번. 자료형을 모름 |
